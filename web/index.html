What is verified?

The finite-system solver has compiled-Wasm execution proofs with explicit input-memory premises. Its mathematics covers arbitrary finite lists; this batch interface accepts up to 16 congruences. The web interface, JavaScript engine, and compiler translation are outside the proof boundary. The execution guarantee is a terminating nontrapping execution and correctness of every normal result.

For valid inputs, incompatibility takes priority over overflow. An overflowing period can still have a small solution. The canonical residue and repeat period must fit signed i64 to be returned; the set of mathematical solutions is unbounded.
